# 会话浏览器

在同时包含 `browser-pages` 和 `browser-files` 能力的新版 asHub 桌面端，打开「插件」并导入本插件 ZIP。安装并启用后新建对话；已有内核可通过重启 asHub 加载插件。旧宿主需要先升级，单独安装插件不会增加桌面宿主能力。插件没有第三方依赖。

在对话中给出 HTTPS 地址，例如「打开这个文档，找出安装命令」。浏览器显示在当前对话右侧。点击「手动接管」可在网页中登录或输入验证码，然后「交还控制」。每个对话、每个站点有独立的登录空间。关闭网页会撤销该页的读取及重复操作授权，登录状态保存在本机。

填写普通表单时先观察、填写，再单独请求点击提交。点击与填写都经过宿主授权检查，默认逐次确认。结果文本可随动作一并核验，结果不确定时先观察，避免重复操作。

每日签到可由定时任务插件向同一对话发送消息。用户可单独授权指定 HTTPS 页面上具备稳定 ID 的独立按钮，在当前浏览器页面有效期间七天内每天最多点击一次。默认在首次操作时确认授权范围。关闭页面、停用插件、退出软件或目标变化后需要重新授权。表单页面不支持这个快捷授权。

支持主文档的文本、标题、可访问按钮、链接与普通文本框。0.2.0 需要包含文件与编辑器接口的新版 asHub 桌面宿主；旧宿主不支持新增操作。跨站登录弹窗、画布和内嵌框架仍请使用原浏览器处理。手动接管期间插件暂停读取和操作。

## 自动授权

支持此设置的新版 asHub 可在「插件 → 编辑配置」中开启「自动批准操作」。
默认关闭。开启后，该插件后续发起的宿主操作无需逐次确认，包括网页点击、填写和表单提交。设置立即生效，关闭后恢复确认。
已经弹出的授权卡仍需处理；页面检查、取消和操作校验继续执行。

## 文件与代码工作流

- `browser_write`：通过最新观察中的 `ref` 替换完整内容。优先传 `sourcePath`，读取当前对话工作目录内的 UTF-8 文件（最大 256 KiB），也可传 `text`，两者只能选一个。普通文本域默认支持；代码编辑器设 `editor: true`，支持暴露公共实例的 Monaco、Ace、CodeMirror 5。写入前核对现有内容，写入后回读；不代表已保存或已执行，需单独点击并核对结果。不支持的编辑器明确拒绝，不盲目模拟按键。
- `browser_upload`：经授权将工作目录内一个文件（最大 32 MiB）的固定快照设置到可见文件输入控件。网站可能立即上传。授权卡显示文件路径、大小和摘要，不向模型返回文件正文。符号链接不能越过工作目录。
- `browser_download`：经授权点击控件，限时 120 秒接收一个同站或 Blob 文件（最大 64 MiB）。收到后先存入私有临时目录，展示实际文件名、大小、SHA-256 和内容预览，必须由用户单独确认，插件自动批准不能跳过。确认后才将固定的已审阅内容写入工作目录的独立 `browser-download-*` 目录；拒绝、取消或确认超时会清理暂存，不写入项目目录。返回 `completed` 仅表示用户确认的实际文件已保存，`triggerVerified: false` 明确表示不能证明由哪次点击产生。完成或结果不确定后返回 `reopenRequired`，下一次下载前必须通过 `browser_open` 重建页面，避免旧操作的迟到额外文件混入。重建丢弃未保存页面状态与旧回调，保留 Cookie、localStorage 等持久化站点数据，不重放操作。明确在点击前被拒绝的操作不要求重建。

建议由已登录的主控对话负责网站操作，其他项目成员提交策略文件和分析下载产物。不同对话的登录空间不会被自动共享。

典型流程：成员生成策略文件 → 主控观察编辑器 → `browser_write` → 单独保存/启动任务并观察结果 → `browser_download` → 成员读取产物。每次页面变化后重新观察，不复用旧引用。

## 开发验证

`npm run test:browser:ui` 覆盖授权、长文本、上传、下载和生命周期回归。真实编辑器测试可在临时目录安装 `codemirror@5.65.21 ace-builds@1.45.2 monaco-editor@0.57.0`，设置 `ASHUB_EDITOR_FIXTURES` 为该目录的 `node_modules` 后运行 `npm run test:browser:editors`。这些包仅用于测试，不随应用打包。
