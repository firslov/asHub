# 会话浏览器

在包含 `browser-pages` 能力的 asHub 桌面端，打开「插件」并导入本插件 ZIP。安装并启用后新建对话；已有内核可通过重启 asHub 加载插件。0.21.2 发行包需要先升级宿主。插件没有第三方依赖。

在对话中给出 HTTPS 地址，例如「打开这个文档，找出安装命令」。浏览器显示在当前对话右侧。点击「手动接管」可在网页中登录或输入验证码，然后「交还控制」。每个对话、每个站点有独立的登录空间。关闭网页会撤销该页的读取及重复操作授权，登录状态保存在本机。

填写普通表单时先观察、填写，再单独请求点击提交。点击与填写都经过宿主授权检查，默认逐次确认。结果文本可随动作一并核验，结果不确定时先观察，避免重复操作。

每日签到可由定时任务插件向同一对话发送消息。用户可单独授权指定 HTTPS 页面上具备稳定 ID 的独立按钮，在当前浏览器页面有效期间七天内每天最多点击一次。默认在首次操作时确认授权范围。关闭页面、停用插件、退出软件或目标变化后需要重新授权。表单页面不支持这个快捷授权。

首版支持主文档的文本、标题、可访问按钮、链接与普通文本框。跨站登录弹窗、文件上传下载、画布和内嵌框架请使用原浏览器处理。手动接管期间插件暂停读取和操作。

## 自动授权

支持此设置的新版 asHub 可在「插件 → 编辑配置」中开启「自动批准操作」。
默认关闭。开启后，该插件后续发起的宿主操作无需逐次确认，包括网页点击、填写和表单提交。设置立即生效，关闭后恢复确认。
已经弹出的授权卡仍需处理；页面检查、取消和操作校验继续执行。
