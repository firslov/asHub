# 设备互联 · Device interconnect

一个可选本地扩展，同时提供「连接其他电脑」和「允许手机、其他电脑访问本机」。任务始终在所选电脑执行，本地对话不受影响。

## 使用

- 在「插件 → 本地扩展」启用设备互联，打开电脑与手机形状的菜单图标。
- **连接其他电脑**：登录原移动访问账号，点击在线设备的「打开工作区」。每台电脑使用独立窗口、对话选择和草稿。登录不会自动共享本机。
- **允许访问本机**：在同一页面填写账号、设备名称和共享目录，核对宿主显示的实际目录范围后确认。首次使用可勾选注册账号。已有手机继续使用原网站、账号和设备。
- **关闭本机访问**：在本机卡片的「更多」中关闭；连接其他电脑的账号保持登录。停用整个插件会关闭两种连接。

本插件随新版 asHub 提供，首次安装默认关闭。旧移动访问已启用时自动迁移到本插件；原先关闭的状态保持关闭。独立 ZIP 需要支持 `backend-connections` 和 `shared-conversations` 的新版宿主，不支持这些能力的旧版不能单独安装新 ZIP。

## 保留与兼容

- 沿用包标识 `ashub-multi-machine`，避免丢失已安装插件的账号凭据。
- 旧设备编号、设备令牌、共享目录和发送回执一次性迁移，不重新创建设备，不要求手机重新配对。
- 控制端登录与本机设备令牌分开加密保存，密码不保存。退出连接账号不会撤销本机共享；关闭本机访问不会注销连接账号。
- 保持网关协议 v1、手机 PWA 和旧桌面执行端兼容。网络连接单独直连，不改变模型 VPN 策略。
- 未知发送结果不会自动重复执行；重启恢复回执后先核对原请求。
- 系统加密存储不可用时不降级为明文。迁移失败时保留原手机连接，待修复存储或更新旧手动安装包后重启重试。

## 分层

插件拥有账号登录、设备发现、网关协议、直连传输、自动重连、发布本机、发送去重回执及页面组织。宿主仅提供注册后端的独立工作区、包隔离加密存储、目录授权和受限的本机会话接口。插件不能通过该接口修改全局设置、访问未授权会话、执行终端命令或授予持续权限。

新目录必须在桌面确认。目录范围用于筛选允许远程访问的对话，不是对模型工具的执行沙箱；对话中的工具仍经过原有权限控制。

支持共享项目/置顶、消息与历史、公式/图片、文件预览、模型/思考深度、消息队列、单次审批及已开放的插件资源。不提供远程桌面、终端管理、插件安装或同步模型密钥。电脑离线时保留草稿，不转到本地执行。

## 验证

`npm run test:multi-machine`、`npm run test:multi-machine:ui`。另有部署侧网关联调 `remote/hub-test.cjs` 和 `remote/multi-machine-test.cjs`；服务器目录不随仓库或插件分发。
