# 个人助手 0.5.3

一个常驻的专属对话，在持续交流中逐渐了解你。只从这段对话整理与召回记忆，普通对话不会自动参与。

需要本次配套的 asHub 主程序与远控网页。单独安装 ZIP 不会让旧发行版获得常驻对话接口。

## 开始使用

安装启用后，左侧出现常驻个人助手入口。首次选择聊天模型，可选择是否自动记住重要信息；确认后直接进入聊天。开启记忆时会在后台自动整理。没有独立设置页或右侧菜单；模型、思考强度和 VPN 使用对话原有控件。

入口右侧直接提供长期记忆开关，没有独立管理弹窗。开启时保留必要授权确认，关闭立即生效。你也可以直接说“记住……”或“忘记……”。关闭后停止学习和召回，保留记录。

首次确认明确授权后台跟随该对话当前及今后选择的模型和 VPN，只读取助手对话。旧的固定模型授权不会自动扩大，如需改用跟随模式，可通过入口开关关闭记忆后重新开启并确认授权。记忆失败或额度耗尽只暂缓整理，已有记忆仍可使用。

## 记忆如何工作

- **原始经历**：复用专属对话的持久化历史与分支 ID，不复制或扫描其他会话。记忆不足时可按需搜索原文，再分段读取核对。回退撤销的来源不参与召回；新分支提供有效依据后重新整理，不继承已撤回的来源和验证反馈。
- **证据条目**：每条自动记忆附带真实用户原文、来源 ID、时间及主体；模型自己的判断、转发任务和外部材料不能作为用户陈述的证据。当前纠正优先于旧记忆。
- **克制召回**：本地中文词项与别名检索，不调用额外模型。每次自动注入最多 4 条、条目总计 2400 字符，使用请求副本，保留历史、图片和工具调用 ID；未命中时可主动搜索记忆与原文。
- **增量整理**：空闲时处理新记录，单个批次至多 6 条记忆。明确偏好和事实可直接生效；推测继续观察；经验与流程需要独立的后续用户效果反馈，明确反例会停用。自我改进限于这些有证据的记忆修订和方法积累，不自行改代码、扩权或安装插件。

设计参考 Anthropic 的 [Components of agent memory](https://www.anthropic.com/research/components-of-agent-memory)：原始经历、结构化记忆、检索与离线整理。本文描述的是 asHub 的具体实现，不声称复刻 Claude 内部架构。

## 界面与手机

桌面与手机复用同一对话和本机记忆库，手机不独立执行整理。远控端只提供关闭长期记忆；首次创建和开启授权仍需在桌面确认。电脑离线时不能使用手机继续访问该助手。

移动访问仍遵循现有目录授权：若手机没有出现助手，请在桌面「移动访问」共享创建时展示的助手工作目录（插件数据目录下的 `workspace`）。不会为了让入口出现而自动扩大目录授权。远控网站也需部署本次配套版本；旧桌面未声明能力时不显示新入口。

## 升级、暂停与恢复

- 首次升级停止旧的全局后台学习并解除旧手动关联。原数据库和记忆保留，不默认迁入新助手。
- 暂停记忆停止新增学习和召回，已有聊天与记忆保留。重新启用需要确认授权。新的跟随授权会沿用对话当前模型和 VPN；旧固定模型授权不会自动扩大。
- 插件停用会隐藏入口并取消后台整理。重新启用仍指向同一对话；如果原对话已删除或创建中断，下次创建须重新确认，并明确提示会新建对话。
- 应用退出后不会继续整理；需要常驻时使用 asHub 后台守护模式。

## 成本与限制

默认每日最多 4 次后台模型请求，按 UTC 日期计数；每次序列化输入不超过 16000 字符，输出预算 4096 tokens。失败和取消的已发起请求也计入额度。每分钟至多一批，忙碌时避让，新近记录等待至少 90 秒。显式「记住」使用现有对话工具调用，不额外启动整理模型。

长历史可能需多日消化，每条自动整理记录最多取前 3000 字符；原文工具可继续分段读取。此实现没有向量服务或知识图谱，不保证语义检索总能命中，也不承诺记住每句话。常见密钥格式会过滤，但无法识别全部敏感信息。原文依据只能核实出处，不能证明模型解释必然正确。

SQLite 保存在本机、按安装包/用户配置隔离。最多 1000 条正式记忆、100 条观察记录和 10000 条总记录，每条最多保留 10 个版本。事务和版本检查防止覆盖并发编辑。

「忘记」清除正文、索引和版本，保留不可逆去重指纹与必要来源 ID，避免从同一证据再次学习。遗忘后如需重新保存，请在助手对话中直接说「请重新记住：完整内容」；仅接受遗忘之后当前用户的明确正向请求及完整原文，转述、引用、疑问和否定不会解除遗忘，不恢复旧记录或旧来源。原聊天、已发送给模型的上下文与外部备份不受影响。不是磁盘取证级擦除。手机响应仅作短期内存缓存，不加入 PWA 静态缓存或通用持久回执日志。

## 验证

```sh
npm run test:personal-assistant
npm run test:personal-assistant:ui
node --test tests/plugin-interactions.cjs tests/regression-remote-connector.mjs
# 在 remote 目录配置 Playwright 后
node remote/render-assistant.cjs
```

覆盖专属对话隔离、原文检索、重复创建、升级迁移、暂停与重启、遗忘、原文代理对边界、真实内核召回、真实 HTTP 授权、远控幂等/撤权以及桌面和 320/390px 手机布局。

对话内遗忘需要明确指定记忆标题、完整内容、来源原文或 ID；名称匹配多条记录时，助手会请你说明要忘记的具体内容。重新记住只保存本次明确请求的内容，不用其他事项的指令恢复旧记忆。

授权页只展示读取范围、后台模型与使用额度。已有聊天及后续消息的边界合并在读取范围中，不显示对话编号、重复字段或空的排除列表；「授权详情」仅保留单次整理额度。展示精简不改变实际授权范围。

本版本需要配套更新 asHub 核心才能获得一次确认、模型跟随、Codex 后台 VPN 和远控资源 ID 修复。插件要求宿主声明 `conversation-resource-popovers` 能力；旧宿主会拒绝安装此版本，请先升级主程序，或继续使用原插件。
