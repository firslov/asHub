# 语音输入

可选本地扩展。点击输入框中的麦克风录音，再次点击结束并转写；结果进入可编辑草稿，由用户手动发送。支持桌面、设备互联工作区和 iPhone PWA 远控。

## 使用

语音输入随新版 asHub 安装，默认关闭。在「插件 → 本地扩展」启用即可。已有的手动安装及配置会继续使用。新用户默认使用「asHub 免费转写」。录音经 asHub 网关转发给腾讯混元 `hy-asr-3.0-preview`，共享密钥仅保存在网关，用户无需填写 API Key。免费服务设有共享额度，用完后可稍后重试或使用自定义转写。

在「语音输入」面板选择「自定义转写」可填写 HTTPS 接口、模型和 API Key。初始示例为 [OpenAI 文件转写](https://developers.openai.com/api/docs/guides/speech-to-text) `/v1/audio/transcriptions` 和 `gpt-transcribe`，也可填写兼容服务。自定义密钥使用桌面系统加密存储，更换接口时须重新填写。升级沿用已有自定义配置，切到免费转写后仍可切回原配置。如果需要删除本机的自定义密钥，点击「清除自定义配置」。

腾讯混元使用以下配置（插件 0.1.1 起）：

- 转写接口：`https://tokenhub.tencentmaas.com/v1/wand/asrproxy/sync_transcribe`
- 模型：`hy-asr-3.0-preview`
- 密钥：开通 TokenHub 后获得的 **TokenHub API Key**，不是腾讯云 SecretId / SecretKey。

插件按此官方地址自动选择 JSON/Base64 协议，从 `output.text` 读取完整结果；不需要额外的服务商开关、COS 上传或公网音频链接。已有相同地址的配置和密钥可继续使用，升级后重启插件即可。其他文件转写接口保持原协议。接口详情见[腾讯官方文档](https://cloud.tencent.com/document/product/1823/135791)。手机始终使用电脑端插件，无需在手机配置密钥或改动远控页面。

需要支持 `composer-inputs`、`plugin-secrets` 的 asHub。免费转写另需支持 PCM 录音的新版本 asHub 和远控网页，旧版 asHub 仍可使用自定义转写。手机需要 HTTPS 和在线、已授权的电脑，配置只在电脑端设置。安装或配置完成后，切换会话或返回前台即可更新入口（已打开页面最多约 15 秒自动更新）。点击录音按钮时才会启用麦克风。

## 行为与边界

- 免费转写使用 16 kHz 单声道 PCM WAV，网关按实际采样数限制在 60 秒内。自定义转写最长 60 秒、最大 4 MiB，录音格式由浏览器决定。识别自动检测语言，不附带聊天历史。
- 正文未变时在原光标位置插入；转写期间编辑过正文则追加，不覆盖编辑。中文输入法候选确认后再插入。
- 取消、切换对话、退出页面、锁屏/切后台、麦克风中断或发送消息均终止本次操作，迟到结果丢弃。不自动发送、重试上传或恢复录音。
- 音频仅在内存暂存。手机录音经已授权的远控通道发往电脑，再由电脑按所选模式送往 asHub 网关或自定义服务。自定义服务可能产生费用，音频处理适用转写服务商的数据政策。
- 停用插件会撤销输入能力并取消未完成转写；重启后恢复加密配置，不恢复未完成录音。失败时保留原草稿，可重新录音。
- 现有模型请求代理设置保持不变。转写使用桌面默认网络策略；设备互联仍使用独立直连通道。

首版不含连续听写、离线识别、语音回复或后台常驻录音。

## 验证

仓库根目录执行 `npm run test:voice-input` 和 `npm run test:voice-input:ui`。WebKit/PWA 测试执行 `node tests/voice-input-browser.cjs`（设置 `PLAYWRIGHT_MODULE`）。测试使用合成/模拟音频及模拟转写服务，不录制用户音频，不产生 API 费用。真实 iPhone 的系统麦克风授权、电话打断与具体服务商识别效果仍需要实机验收。

腾讯适配回归：插件目录执行 `npm test`；完整工作区构建后执行 `npm run test:integration`，覆盖桌面本地 HTTP 和真实远控网关 → 设备发布器 → 授权通道 → 插件的转写与取消。腾讯请求使用模拟服务验证协议；实际编码支持、识别质量和时延需使用有效 TokenHub 账号实测。
