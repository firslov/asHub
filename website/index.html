一个入口，管理扩展

安装指南 ↗
  1. 选择扩展

    打开「插件 → 本地扩展」启用随附插件，其他扩展可从可信 ZIP 安装。

  2. 配置与授权

    按需配置账号和权限。自动批准默认关闭，由你逐个插件决定是否开启。

  3. 开始使用

    新建对话加载启用的工具；已有对话按界面提示重新加载。停用后对应菜单随之收起。

设备互联、定时任务、语音输入和 Kimi Coding Plan 同样随附；桌面控制仅随 macOS 版提供。个人助手需单独安装；微信机器人是另有安装说明的 agent-sh 扩展示例。定时任务需电脑保持唤醒，桌面控制需系统授权。

04 / PICK UP WHERE YOU LEFT OFF

移动访问 预览

离开电脑
工作仍在手边

电脑负责执行，手机接着对话。查看进展、补充想法、确认操作，让一段工作自然延续。

  1. 在桌面授权

    在「插件 → 本地扩展」启用「设备互联」，打开工具栏入口，选择「允许访问本机」，登录并确认共享目录

  2. 保存恢复码

    若显示恢复码，妥善保存后点击「恢复码已保存」

  3. 在手机继续

    登录同一账号并选择执行电脑。可打开已授权的对话或个人助手，启用语音输入后，转写文字会写入可编辑草稿

打开移动网页版 ↗使用须知

电脑需联网、保持唤醒并运行 asHub。可开启「后台运行」以便关闭窗口后继续访问。电脑之间也可通过「设备互联」连接；查看其他设备不会自动共享本机。

macOS 一行命令安装
curl -fsSL https://raw.githubusercontent.com/firslov/asHub/main/install.sh | bash

脚本自动识别 Apple Silicon / Intel，安装至 /Applications，并移除隔离标记。也可以直接下载 DMG；如被系统拦截，在「系统设置 → 隐私与安全性」选择「仍要打开」。

Linux AppImage 如何运行

下载与你的 x64 设备对应的 AppImage，在文件所在目录赋予执行权限后启动。

chmod +x ./asHub-*.AppImage ./asHub-*.AppImage
开发者：从源码运行

推荐 Node.js 22 或 24（最低 22.12.0，不支持 26 及以上）。以下命令使用 nvm 切换至 .nvmrc 指定版本。

git clone https://github.com/firslov/asHub.git cd asHub nvm install && nvm use npm ci npm run electron:dev

只需浏览器界面时，运行 npm start -- --port 7878，然后访问 http://localhost:7878。

A FEW THINGS TO KNOW

开始前的小问题

asHub 免费吗？需要准备什么？

asHub 以 MIT 许可证开源。使用前需配置支持的模型 API，或使用受支持的 Codex 登录；计费和额度以提供商为准。

可以只用浏览器访问吗？

可以。桌面版与本地 Web 版使用同一套客户端。启动本地服务后即可通过浏览器访问；也可使用移动访问预览功能，通过账号连接在线桌面。自行部署跨设备服务时，需使用访问令牌与可信网络或 HTTPS 反向代理。

手机上为什么看不到全部对话？

移动访问仅展示所选电脑已授权目录中的对话。请在桌面检查共享目录；工作目录已移动或删除的对话需要先恢复或调整，归档对话需要先恢复。终端与文件浏览暂不在移动端范围内。

关闭电脑上的窗口后，还能远控吗？

在「设置 → 后台运行」开启「关闭窗口后继续运行」，任务与远控连接会保留。该功能默认关闭，可从状态栏重新打开窗口或退出应用。需要远控时可选防止自动休眠，屏幕仍可熄灭；合盖、手动休眠或断网仍可能使连接中断。

插件配置保存后，什么时候生效？

在「插件 → 本地扩展」启用随附插件，或通过「安装插件」导入可信 ZIP。启用工具后可新建对话；已有对话按界面提示重新加载。

个人助手会读取我的其他对话吗？

不会。个人助手只从已授权的专属对话整理和召回记忆。首次创建与开启记忆需在桌面确认；共享助手工作目录后，手机可继续同一段对话，也可关闭长期记忆。

手机断开或电脑休眠后，任务会怎样？

手机断开不会停止电脑上的任务；连接恢复后会自动重连。同步用时过长时，可选择「重新同步此对话」，保留草稿和待确认发送状态。电脑离线或休眠时，需要唤醒并保持 asHub 运行。

对话保存在什么地方？

会话历史保存在本地，可在重启后恢复，也支持导出 Markdown。移动访问通过 HTTPS/WSS 中转，服务不持久保存对话正文，但可读取转发内容，不属于端到端加密。使用云端模型时，相关内容会发送至你配置的提供商。

支持哪些系统？

macOS 支持 Apple Silicon 与 Intel；Windows 提供 x64 安装包；Linux 提供 x64 AppImage。桌面安装包已包含运行环境，无需单独安装 Node.js。Windows 使用 Bash 命令与 Git 工作树需安装 Git for Windows。
