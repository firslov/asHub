前往 GitHub Releases 获取最新安装包

macOS 一行命令安装
curl -fsSL https://raw.githubusercontent.com/firslov/asHub/main/install.sh | bash

脚本自动识别 Apple Silicon / Intel，安装至 /Applications，并移除隔离标记。也可以直接下载 DMG；如被系统拦截，在「系统设置 → 隐私与安全性」选择「仍要打开」。

Linux AppImage 如何运行

下载与你的 x64 设备对应的 AppImage，在文件所在目录赋予执行权限后启动。

chmod +x ./asHub-*.AppImage ./asHub-*.AppImage
开发者：从源码运行

使用项目固定的 Node.js 22（最低 22.12.0）。以下命令使用 nvm 切换至 .nvmrc 指定版本。

git clone https://github.com/firslov/asHub.git cd asHub nvm install && nvm use npm ci npm run electron:dev

只需浏览器界面时，运行 npm start -- --port 7878，然后访问 http://localhost:7878。

A FEW THINGS TO KNOW

开始前的小问题

asHub 免费吗？需要准备什么？

asHub 以 MIT 许可证开源。使用前需配置支持的模型提供商与 API 凭据；模型调用费用由所选提供商收取。

可以只用浏览器访问吗？

可以。桌面版与 Web 版使用同一套客户端。启动本地服务后即可通过浏览器访问；跨设备访问需配置监听地址并使用访问令牌，建议通过可信网络或 HTTPS 反向代理连接。

对话保存在什么地方？

会话历史保存在本地，可在重启后恢复，也支持导出 Markdown。使用云端模型时，相关请求内容会发送至你配置的模型提供商。

支持哪些系统？

macOS 支持 Apple Silicon 与 Intel；Windows 提供 x64 安装包；Linux 提供 x64 AppImage。桌面安装包已包含运行环境，无需单独安装 Node.js。
