01

会话与历史

同时推进多条任务线，历史永不丢失，随时回到任何一个分支点。

多会话工作区

侧边栏创建、切换、搜索、关闭会话，支持分组与归档——几十条会话也能一屏管理。

会话持久化与自动标题

分支树时间旅行

一键导出 Markdown

任意会话导出为 Markdown 文档，归档、分享、二次加工零成本。

Install

一分钟内开始

macOS 提供一键脚本，Windows 与 Linux 从 Releases 下载对应安装包即可。

terminal
$ curl -fsSL https://raw.githubusercontent.com/firslov/ashub/main/install.sh | bash

一键安装到 /Applications 并自动清除 Gatekeeper 隔离标记（Apple Silicon）。 也可以在 Releases 下载 .dmg， 拖入 Applications 后执行 xattr -dr com.apple.quarantine "/Applications/asHub.app"。

powershell
> # 从 Releases 下载 asHub-Setup.exe，双击安装 前往 Releases

从 Releases 下载 Windows 安装包（x64）。 需要 PowerShell 5.1+，Windows 10 / 11 自带。

terminal
$ chmod +x asHub-*.AppImage && ./asHub-*.AppImage

从 Releases 下载 AppImage，赋予执行权限即可运行。

从源码运行

terminal — Node.js ≥ 20.3
$ git clone https://github.com/firslov/ashub.git cd ashub && npm install && npm run electron:dev

也可以无窗口运行 npm start -- --port 7878，用任意浏览器打开 http://localhost:7878 作为界面。
