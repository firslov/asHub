前往 GitHub Releases 获取最新安装包

macOS 一行命令安装
curl -fsSL https://raw.githubusercontent.com/firslov/asHub/main/install.sh | bash

脚本自动识别 Apple Silicon / Intel，安装至 /Applications，并移除隔离标记。也可以直接下载 DMG；如被系统拦截，在「系统设置 → 隐私与安全性」选择「仍要打开」。

Linux AppImage 如何运行

下载与你的 x64 设备对应的 AppImage，在文件所在目录赋予执行权限后启动。

chmod +x ./asHub-*.AppImage ./asHub-*.AppImage
开发者：从源码运行

使用项目固定的 Node.js 22（最低 22.12.0）。以下命令使用 nvm 切换至 .nvmrc 指定版本。

git clone https://github.com/firslov/asHub.git cd asHub nvm install && nvm use npm ci npm run electron:dev

只需浏览器界面时，运行 npm start -- --port 7878，然后访问 http://localhost:7878。

A FEW THINGS TO KNOW

开始前的小问题

asHub 免费吗？需要准备什么？

asHub 以 MIT 许可证开源。使用前需配置支持的模型提供商与 API 凭据；模型调用费用由所选提供商收取。

可以只用浏览器访问吗？

可以。桌面版与本地 Web 版使用同一套客户端。启动本地服务后即可通过浏览器访问；也可使用移动访问预览功能，通过账号连接在线桌面。自行部署跨设备服务时，需使用访问令牌与可信网络或 HTTPS 反向代理。

手机上为什么看不到全部对话？

移动访问仅展示所选电脑已授权目录中的对话。请在桌面检查共享目录；工作目录已移动或删除的对话需要先恢复或调整，归档对话需要先恢复。终端与文件浏览暂不在移动端范围内。

关闭电脑上的窗口后，还能远控吗？

v0.20.8 可在「设置 → 后台运行」开启「关闭窗口后继续运行」，任务与远控连接会保留。该功能默认关闭，可从状态栏重新打开窗口或退出应用。需要远控时可选防止自动休眠，屏幕仍可熄灭；合盖、手动休眠或断网仍可能使连接中断。

插件配置保存后，什么时候生效？

在右侧「插件」菜单中查看状态、启停本地扩展或编辑配置。修改在会话内核下次启动时生效；已有会话请在任务结束后重启 asHub。插件在本机运行，请只使用可信来源。

手机断开或电脑休眠后，任务会怎样？

手机断开不会停止电脑上的任务。电脑离线或休眠时无法远程操作，需唤醒并保持 asHub 运行。网页可添加到手机主屏幕，但不提供离线对话历史。

对话保存在什么地方？

会话历史保存在本地，可在重启后恢复，也支持导出 Markdown。移动访问通过 HTTPS/WSS 中转，服务不持久保存对话正文，但可读取转发内容，不属于端到端加密。使用云端模型时，相关内容会发送至你配置的提供商。

支持哪些系统？

macOS 支持 Apple Silicon 与 Intel；Windows 提供 x64 安装包；Linux 提供 x64 AppImage。桌面安装包已包含运行环境，无需单独安装 Node.js。Windows 使用 Bash 命令与 Git 工作树需安装 Git for Windows。
